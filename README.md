# Moon Colony Bloodbath — Multiplayer Edition

Browser game with five colonies, 1–5 humans, AI bots, scanned artwork and responsive mobile interface.

**Start here:** [SETUP.md](SETUP.md). Online rooms require your own Firebase Realtime Database and Anonymous Authentication; GitHub Pages alone cannot synchronize devices. After setup, create a room, share a link, then launch when your friends join.

The original local game and portable JSON saves remain available from **Same-device / offline**.

Security and artwork rights warnings are included in SETUP.md.
