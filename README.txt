MOON COLONY BLOODBATH - MULTIPLAYER EDITION

To enable multi-device online play, follow SETUP.md.
GitHub Pages hosts the site, while Firebase provides room codes and live updates.
Online mode needs a configured firebase-config.js, an enabled Anonymous Auth
provider, and firebase-rules.json published in Realtime Database Rules.

LOCAL MODE: Choose Same-device / offline on the main menu. Your original
five-colony game with bots, scanned cards, and save/load remains available.

To upload to GitHub Pages: upload the entire EXTRACTED contents of this ZIP
(index.html, .js, .css and assets folder) to your repository root.

See SETUP.md for gameplay, costs, security limitations and artwork rights.
